# PrepMate AI Frontend

React + TypeScript + Vite frontend for PrepMate AI.

## Setup

```cmd
cd frontend
npm install
npm run dev
```

The frontend uses:

`VITE_API_BASE_URL=http://127.0.0.1:8000`

You can copy `.env.example` to `.env` if you want to override the backend URL.

Build for production:

```cmd
npm run build
```
